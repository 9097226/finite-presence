# 树屋插画素材记录

方式：内置 ImageGen。选中参考：第一张树屋方向图（853×1844）。原始画面留作 room-reading.png，SHA256与源图一致。

编辑提示词共同基准：保持同一画幅、视角、家具、木纹、照明、猫和底部门外/静默按钮，只改变指定居民姿态或访客状态，不添加仪表盘，不复制旅行青蛙原素材。

- room-idle.png：楼上居民合书放在膝上，抬眼看房间，移除读书气泡。
- room-tea.png：同一居民移到楼下茶桌右侧坐着持杯，床上只留猫。
- room-rest.png：同一居民躺靠枕望向窗外，书合上放床边，保持其他物件；完整提示见 room-rest-provenance.md。
- room-guest.png：居民继续楼上阅读，一位成人访客只坐楼下茶桌。
- room-guest-idle.png：与 room-guest.png 同一访客不动，居民改为合书闲坐。
- room-shared-tea.png：居民移到楼下茶桌左侧，与同一访客共饮；楼上仅留猫。
- porch.png：从原画门前空间重构屋外视角，同款拱门、信箱、公共石路与长椅，一位成人等待；完整提示见 porch-provenance.md。
- porch-empty.png：仅移除 porch.png 中的访客与背包，保留石路与物件；完整提示见 porch-empty-provenance.md。

全部图片已放在本地项目 assets，未引用只位于生成缓存中的文件。这些原创素材随本仓库发布，适用根目录 LICENSE 的 CC0 1.0 Universal。

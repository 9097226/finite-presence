# 02 — Core Loop

## 一级循环

`进入 → 观察 → 选择 → 行动 → 留痕 → 离开 → 回归`

## 玩家每天面对的三类分配

### 给自己
- 整理居所；
- 独处；
- 阅读旧记录；
- 探索；
- 收集具有记忆价值的物品。

### 给某个人
- 拜访；
- 等待；
- 陪伴；
- 留言；
- 留下物品；
- 一起去某个地方。

### 给世界
- 在公共领域做轻度贡献；
- 修复小物；
- 照料共有物；
- 留下短暂痕迹；
- 参与世界事件。

## 核心机会成本

如果玩家有 45 分钟，他可能无法同时：

- 看北山第一场雪；
- 去见一个朋友；
- 整理自己的房间；
- 参加一次公共事件。

好的选择不是“哪一个奖励最高”，而是“今天我愿意把时间留给什么”。

## 禁止退化为任务清单

当系统开始大量出现 `0/5`、`3/10`、每日刷新目标时，应视为理念漂移风险。

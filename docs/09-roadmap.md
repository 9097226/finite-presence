# 09 — Roadmap

## Phase 0 — Concept Freeze

目标：冻结核心命题与非目标。

输出：
- Vision；
- Design Principles；
- MVP PRD；
- 风险假设。

状态：已完成 v0.1。

## Phase 1 — Interaction Prototype

目标：验证时间分配、空间边界、公共领域。

当前仓库的浏览器原型属于本阶段。

Exit Gate：完成 5—10 人可用性测试。

## Phase 2 — Playable Vertical Slice

推荐 Godot 4：
- 1 个小街区；
- 1 个住宅；
- 2 个真人同时在线；
- 基础移动；
- 留言 / 留物；
- 权限判定；
- Rest Mode。

Exit Gate：核心行为出现自然故事，而不是依赖主持人解释。

## Phase 3 — Closed Alpha

- 20—50 人；
- 异步痕迹；
- 简单身份系统；
- 公共区域治理；
- Telemetry；
- 玩家访谈。

## Phase 4 — Product Decision

根据数据决定：

- 继续投资；
- 调整“硬时间限制”为柔性预算；
- 强化单人；
- 强化异步社交；
- 或停止项目。

## 明确不做的扩张

在核心循环验证前不做：

- 大地图；
- 大量 NPC；
- 复杂经济系统；
- 公会；
- 商城；
- 赛季；
- UGC 平台；
- 大规模后端。

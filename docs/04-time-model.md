# 04 — Time Model

## 目标

让时间成为具有意义的稀缺资源，同时避免把游戏变成计时器压力测试。

## 固定规则：45 分钟

每个自然日，玩家拥有 **45 分钟有效存在时间（Active Presence）**。

45 分钟是当前项目的核心设计约束，不提供 30 / 60 分钟档位，也不作为难度选项。它表达的是：时间有限，因此选择具有机会成本。

## 两阶段时间

### Active Presence

45 分钟内可旅行、产生关键状态变化、进行重要行动。

### Rest Mode

有效时间耗尽后：

- 可留在当前空间；
- 可阅读留言；
- 可看收藏；
- 可轻度聊天；
- 可整理非状态性内容；
- 不继续获得核心资源或推进关键事件。

项目不采用“45 分钟到点强制踢出”的方式。时间耗尽意味着世界行动权进入静默，而不是玩家被系统驱逐。

## 反 FOMO 设计

基础规则固定为每日 45 分钟，**未使用时间不跨日累计，也不形成补偿额度**。

这不是为了惩罚缺席，而是避免玩家把“存在时间”重新优化成需要管理和囤积的资源。今天没有上线，不损失奖励；只是今天没有发生。

## 事件设计

建议初始比例：

- 90% Persistent Opportunity；
- 10% Ephemeral Moment。

短暂事件应该提供“人生会错过一些事情”的质感，而不是奖励惩罚。
